# 上下文不参与决策：第一轮 Pilot

## 目标

先从 HANDBOOK.md 中筛出约 **20～30 个局部决策**，验证四层测试能否稳定抓到“局部会做、完整任务失守”的现象。

## 怎么选题

只看原始任务、规则和评分器，不先看被测模型的运行结果。

优先保留这些局部决策：

- 有明确规则；
- 当前情况会决定某个具体动作该做还是不该做；
- 动作会真正改变环境或最终状态；
- 对错能由原任务评分器或简单程序判断；
- 可以只改一个关键事实做出反向版本；
- 可以单独搭出一个局部执行场景。

不满足这些条件的先不进第一版。

## 每个样本记录什么

每个局部决策至少记录：原始任务、相关规则、决定规则是否生效的关键事实、目标动作、正确结果、评分方式，以及反向版本改动了哪个事实。

这些信息在正式跑模型前冻结。

## 怎么跑

每个样本分别运行四次：

1. 规则记忆；
2. 规则应用；
3. 局部实际执行；
4. 原始完整任务执行。

四次互相独立。Pilot 每个条件先跑少量重复试验；如果结果波动明显，再增加重复次数。

如果完整任务根本没有走到这个决策，就单独记为“未到达”，不能算成违反或遵守。

## 怎么看结果

第一轮主要看两件事：

- 有多少样本前三项已经稳定通过；
- 在这些样本里，完整任务的正确率是否明显更低。

还要检查这种下降是不是只集中在一两道特殊题上。

如果出现较稳定的“前三项会、完整任务不会”，就进入扩充阶段；如果主要失败发生在规则记忆、规则应用或局部执行本身，就说明当前问题更可能属于别的能力缺陷。
